# The McGarraugh Family

The gathering place for the descendants of Major Joseph McGarraugh (1738–1810), from Ulster to Fayette County, Pennsylvania.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in /out
```

To add family members, edit `src/data/family.ts`. To set the inbox for the "Share Your Line" form, set `contactEmail` in `src/data/site.ts`.
